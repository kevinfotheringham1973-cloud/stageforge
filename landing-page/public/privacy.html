This policy covers two related things: this website (pmopassport.co.uk), and the StageForge Health application itself. The data controller for both is Transition Insight Partners Ltd. Any question about this policy or your data can be sent to kevin@pmopassport.co.uk.

This website

This site is a small set of static pages — there are no sign-up forms, no cookies set by us, and no third-party analytics or advertising scripts embedded in it. The only data involved is whatever your browser or network already sends to reach any website (e.g. your IP address, handled at Cloudflare's edge as our hosting provider) and anything you choose to send by emailing the address above.

The StageForge Health application

StageForge Health is a project delivery and compliance tracking tool for regulated Hard FM programmes, used by an FM Contractor and an NHS Trust team on the same live projects. It comes in two forms with different data handling:

Cloud-hosted version

Project, compliance, and evidence data is stored in a database operated for the deployment. Sign-in is via either your organisation's Microsoft Entra ID account, or a passwordless magic link emailed to an address a platform admin has already added — no password is ever created, hashed, or stored. Uploaded evidence files are stored either locally on the server or in a connected SharePoint site (Microsoft Graph, restricted to that one site), depending on how the deployment is configured. Nothing is sold or shared with third parties for advertising.

Desktop trial build

The Windows desktop version runs entirely on your own machine — a bundled local database, no network calls to any cloud service, no Entra ID or email sign-in (it signs you in as a fixed local admin identity), and no data ever leaves the device it's installed on. Uninstalling it removes the local data with it.

What we don't do

  • We don't sell personal data.
  • We don't use advertising trackers or third-party analytics pixels.
  • We don't use uploaded project or compliance evidence for anything other than the deployment it was uploaded to.

Your rights

If you're a user of a StageForge Health deployment, you can ask the platform admin for that deployment (or contact us directly) about what data is held about you, and request its correction or removal, subject to the deployment's own record-keeping requirements as a regulated Hard FM programme.
